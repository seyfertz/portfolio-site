# Контур

Витрина веб-разработчика. Включает интерактивные примеры онлайн-записи, расчёт стоимости и форму заявки с доставкой в Telegram.

## Публикация на Vercel

1. Импортируйте репозиторий как проект **Other**. В качестве корня используйте папку с `index.html` и `vercel.json`.
2. Добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменные окружения **Production**. Пример имён переменных находится в [`.env.example`](.env.example).
3. Откройте опубликованный сайт, отметьте согласие и проверьте доставку заявки в Telegram.

[lead-demo.js](lead-demo.js) задаёт публичный контакт и пример заявки. Посетитель может приложить к примеру расчёт из конструктора.
