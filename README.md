# Контур

Демовитрина веб-разработчика. Включает интерактивные примеры онлайн-записи, калькулятор сметы и тестовую форму с доставкой в Telegram.

## Публикация на Vercel

1. Импортируйте репозиторий как проект **Other**. В качестве корня используйте папку с `index.html` и `vercel.json`.
2. Добавьте `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` в переменные окружения **Production**. Пример имён переменных находится в [`.env.example`](.env.example).
3. Откройте опубликованный сайт, отметьте согласие и отправьте тестовую заявку. Она поступит в Telegram с отметкой «Тестовая заявка · Контур».

[lead-demo.js](lead-demo.js) задаёт публичный контакт для вопросов по демо и пример заявки. В этом режиме форма отправляет образец, а посетитель может приложить расчёт из конструктора.
